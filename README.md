# 축의금 접수 · 정산

결혼식 접수대에서 축의금을 빠르게 기록하고, 식사 인원과 현금·봉투를 정확하게 대조하기 위한 앱입니다.
설치나 회원가입 없이 브라우저에서 바로 실행되며, 데이터는 사용하는 기기에 자동 저장됩니다.

**바로 사용하기: <https://narayo20.github.io/wedding-reception/>**

태블릿·휴대폰 브라우저에서 위 주소를 열고 **홈 화면에 추가**하면 앱처럼 전체 화면으로 사용할 수 있습니다.

## 주요 기능

- **빠른 접수**: 신랑측/신부측 선택, 금액 버튼(3만·5만·10만·20만·30만·50만), 성함·관계·식사 인원·결제 수단 입력
- **봉투 번호 자동 부여**: 신랑측/신부측별로 1번부터 순서대로 부여
- **실수 방지**: 저장 직후 실행 취소, 명단에서 수정·삭제, 삭제 기록 복구
- **양가 집계**: 건수, 축의금, 식사 인원을 신랑측/신부측으로 분리 집계
- **정산 대조**: 기록된 현금과 실제 계산 금액, 기록된 봉투 수와 실제 봉투 수의 차이를 즉시 표시
- **마감 점검**: 실제 현금이나 봉투 수가 기록과 다르면 마감 확인창에서 경고
- **예상 식대**: 1인 식대 × 식사 인원으로 예상 식대와 잔액 계산
- **마감 잠금**: 정산이 끝나면 입력을 잠가 실수로 수정되는 것을 방지
- **내보내기**: CSV(엑셀), JSON 백업/복원, 정산 요약 복사, 서명란이 포함된 정산서 인쇄
- **오프라인**: 인터넷이 끊겨도 접수·정산 가능, 홈 화면에 앱처럼 설치

## 실행 방법

### 1. 인터넷에서 바로 사용 (권장)

<https://narayo20.github.io/wedding-reception/> 을 열면 PC·태블릿·휴대폰 어디서든 바로 사용할 수 있습니다.
GitHub Pages로 호스팅되며, 접수 데이터는 서버가 아닌 **해당 기기 브라우저에만** 저장됩니다.

### 2. 노트북에서 직접 실행

Node.js가 설치되어 있다면 프로젝트 폴더에서:

```bash
node server.js
```

브라우저에서 `http://localhost:4174` 을 엽니다.

> `index.html` 파일을 더블클릭해도 대부분 동작하지만, 홈 화면 설치와 오프라인 캐시는 `node server.js` 로 열 때만 동작합니다.

### 3. 태블릿·휴대폰에서 접속 (로컬 서버)

1. 노트북과 태블릿을 **같은 Wi-Fi**에 연결합니다.
2. `node server.js` 실행 시 콘솔에 표시되는 `Tablet: http://192.168.x.x:4174` 주소를 태블릿 브라우저에서 엽니다.
3. 브라우저 메뉴에서 **홈 화면에 추가**를 선택하면 앱처럼 전체 화면으로 실행됩니다.
   - 아이폰·아이패드: Safari 공유 → 홈 화면에 추가
   - 안드로이드: Chrome 우측 상단 메뉴 → 홈 화면에 추가

### 포트 변경

```bash
PORT=8080 node server.js
```

Windows PowerShell에서는:

```powershell
$env:PORT=8080; node server.js
```

## 사용 순서

1. **설정**에서 예식 날짜, 신랑·신부 이름, 예식장, 1인 식대를 입력합니다.
2. **접수** 화면에서 하객의 측·성함·금액·식사 인원을 입력하고 `접수 저장`을 누릅니다.
   - 금액 버튼을 누르면 빠르게 입력됩니다.
   - 결제 수단이 계좌이체라면 `계좌`를 선택합니다.
3. 접수 중 잘못 입력했다면 저장 직후 나타나는 `실행취소`를 누르거나 **명단**에서 수정합니다.
4. 접수가 끝나면 **정산**에서:
   - 실제 현금 합계를 입력해 기록과 비교합니다.
   - 실제 봉투 수를 입력해 건수와 비교합니다.
   - 양가별 금액·인원과 예상 식대를 확인합니다.
5. `정산서 인쇄` 또는 `CSV 내보내기`로 결과를 남깁니다.
6. 모든 확인이 끝나면 `마감하기`를 눌러 입력을 잠급니다.

## 정산 화면 읽는 법

| 항목 | 의미 |
| --- | --- |
| 기록된 현금 | 앱에 현금으로 입력된 축의금 합계 |
| 실제 계산 | 접수대에서 실제로 센 현금 합계 |
| 기록된 봉투 | 현금으로 접수된 건수 (= 봉투 수) |
| 실제 봉투 | 실제로 모인 봉투 수 |
| 축의금 − 식대 | 총 축의금에서 예상 식대를 뺀 금액 |

차액이 0이면 `✓ 기록과 일치합니다`로 표시됩니다.

## 데이터 보관과 백업

- 모든 데이터는 **해당 기기 브라우저의 localStorage**에 자동 저장됩니다.
- 브라우저 방문 기록/사이트 데이터를 삭제하면 접수 내역도 사라집니다. 행사 전후로 **JSON 백업**을 꼭 받아 두세요.
- 여러 기기에서 나눠 접수하면 데이터가 합쳐지지 않습니다. 한 기기에서 접수하고, 필요하면 JSON 백업으로 옮기세요.
- 백업 파일에는 접수 내역, 예식 정보, 정산 입력값, 변경 기록이 모두 들어 있습니다.

## GitHub에 저장 · 배포

- 저장소: <https://github.com/narayo20/wedding-reception>
- 호스팅: GitHub Pages (`main` 브랜치 루트를 그대로 배포)

코드를 수정한 뒤 아래처럼 올리면 1~2분 안에 사이트에 자동 반영됩니다.

```bash
git add .
git commit -m "수정 내용"
git push
```

- 이미 홈 화면에 추가한 기기는 앱을 완전히 닫았다가 다시 열면 새 버전을 받습니다.
- 화면 파일을 수정했다면 `sw.js`의 `VERSION` 값을 올려 주세요(예: `v1` → `v2`). 그래야 오프라인 캐시가 새 파일로 교체됩니다.
- GitHub Pages 주소는 저장소 이름을 바꾸면 함께 바뀝니다.

```

```

## 참고 사항

- 접수 데이터는 서버로 전송되지 않습니다. 모든 계산은 브라우저 안에서 이루어집니다.
- 브라우저의 시크릿/프라이빗 모드에서는 창을 닫을 때 데이터가 삭제될 수 있습니다.
- 정산 마감 후에도 설정에서 마감을 해제하면 수정할 수 있습니다.
- 삭제는 실제로 지우지 않고 기록을 남기므로, 설정의 **최근 변경 내역**에서 복구할 수 있습니다.
